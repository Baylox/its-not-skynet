## Contexte d'usage
Applique le principe d'inversion de dépendance lors de la génération de code orienté objet en Java, TypeScript, C#, PHP ou Rust. Chaque classe publique ou concept métier est adossée à une abstraction (interface ou trait). Convention de nommage : préfixer le nom de la classe par `I`.
