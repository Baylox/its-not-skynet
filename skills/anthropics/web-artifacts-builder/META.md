# Meta — web-artifacts-builder

## Source
- Auteur : Anthropic (officiel)

## Contexte d'usage
Construit des artifacts HTML complexes (React + Tailwind + shadcn/ui) bundlés en un seul fichier auto-contenu. Pour des artifacts nécessitant state management, routing ou composants shadcn/ui — pas pour du HTML simple.
