# Meta — claude-api

## Source
- Auteur : Anthropic (officiel)

## Contexte d'usage
Aide à construire, déboguer et optimiser des apps utilisant l'Anthropic SDK. Couvre le prompt caching, la migration entre versions de modèles, et toutes les features Claude (tool use, thinking, batch, files). Se déclenche dès qu'un fichier importe `anthropic` ou `@anthropic-ai/sdk`.

## Environnement testé
- Outil : Claude Code
- Compatibilité déclarée : Claude Code, Codex, Gemini CLI, Cursor
