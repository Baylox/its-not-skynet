# Meta — theme-factory

## Source
- Auteur : Anthropic (officiel)
- Statut : **stable**
- Repo : https://github.com/anthropics/skills

## Contexte d'usage
Applique un thème visuel (couleurs + polices) à n'importe quel artifact : slides, docs, HTML, etc. Propose 10 thèmes pré-définis ou génère un thème custom à la volée. S'intègre après création d'un artifact pour le styliser.

## Environnement testé
- Outil : Claude Code
- Compatibilité déclarée : Claude Code, Codex, Antigravity CLI, Cursor
