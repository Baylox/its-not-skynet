# its-not-skynet

> Ressources CLI/IA validées par des humains. Pas de magie. Pas de réseau non maîtrisé. Juste des outils qui marchent.

[![not skynet](https://img.shields.io/badge/not-skynet-green)](https://github.com/its-not-skynet)

## Ce que c'est

Un repo communautaire de ressources pour le développement avec des outils IA en CLI —
Claude Code, MCP, Ollama et compagnie. Chaque ressource a été créée ou testée en
conditions réelles par son auteur.

## Contenu

| Dossier | Description | Détails |
|---------|-------------|---------|
| [`hooks/`](hooks/README.md) | Scripts exécutés par Claude Code à des événements précis | PreToolUse, PostToolUse, Notification... |
| [`skills/`](skills/README.md) | Skills Claude Code réutilisables | Slash commands, agents spécialisés |
| [`configs/`](configs/README.md) | Fichiers de configuration copiables | settings.json, .mcp.json... |
| `architecture/` | Schémas et décisions d'architecture | |
| `subagents/` | Définitions de subagents | |

## Démarrage rapide

Chaque ressource vit dans son propre dossier avec un `META.md` qui explique ce qu'elle fait et comment l'installer. Commencez par parcourir les dossiers ci-dessus.
